bamrc Samplesheet Builder

Fill in one row per sample (tumor or normal), then download the CSV for main.nf --samplesheet. Samples with the same patient are merged into one VCF. reference is a genome version (e.g. hg38); leave it blank to use the pipeline default (hg38). The BAM/CRAM index (.bai/.crai) is found automatically next to bam_file. Everything stays in this browser and nothing is uploaded.
To paste many cells at once, copy a block from Excel, Google Sheets or a CSV, click the cell where it should start, and press Ctrl+V. It fills right and down, adding rows as needed. If the first copied line is the header, columns are matched by name.

Drag a column header's right edge to resize it; double-click the edge to fit.
